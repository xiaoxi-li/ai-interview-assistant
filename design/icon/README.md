# 轻松面试 · Logo 设计（汉字「简」）

> 主体是汉字 **「简」**（艺术字体方案，多套风格供选）。
> 色值与圆角严格取自客户端现有视觉令牌，与界面（浅色 / 深色双主题）天然一致。

## 一、设计意图

| 客户端定位 | 图形语言 |
| --- | --- |
| 「轻松面试」的产品名 | 一个 **简** 字，比字母组合更直接、更短促有力 |
| 本地优先 · 低资源 · 低复杂度 | **简** = 简单 / 简约 / 化繁为简，本身就是产品主张 |
| 让面试这件事变简单 | 单字标记，16px 仍可辨认，托盘 / 任务栏不糊 |

## 二、规格

- 画布 1024×1024，圆角比例 **22.37%**（系统级方圆形，四角透明）
- 色板：背景对角渐变 `#5B7CFA → #2B46C4`；主色 `#4F6BED`；字为白→浅蓝竖向微渐变
- 字面占画布 **62%**，按**墨迹外接框归一化**——各字体字面大小差异很大，归一化后体量一致，只有风格不同
- **字重补偿**：书法体笔画细，在图标尺寸下会被背景吃掉。渲染时按 1600px 尺度做描边外扩（10~17px），使各方案视觉重量可比

## 三、候选方案（`final/preview.png` 为对比图）

| key | 字体 | 风格 | 作为图标的评价 |
| --- | --- | --- | --- |
| `hupo` | 华文琥珀 | 圆润厚重 · 装饰感最强 | **最推荐**：笔画饱满、识别度高，最像一枚 App 图标 |
| `liti` | 华文隶书 | 古朴典雅 · 蚕头燕尾 | 有文化厚度，横画舒展 |
| `xingkai` | 华文行楷 | 行云流水 · 手写气韵 | 灵动，但结构偏散 |
| `xinwei` | 华文新魏 | 魏碑刀刻 · 方正有力 | 稳、硬朗，气质偏正式 |
| `yaoti` | 方正姚体 | 美术字 · 横细竖粗 | 工整现代，偏「工具感」 |
| `shuti` | 方正舒体 | 舒同体 · 飘逸洒脱 | 洒脱，笔画仍偏细 |
| `kaiti` | 华文楷体 | 端正工整 · 传统书风 | 端正，但略「教科书」 |
| `zhongsong` | 华文中宋 | 宋体骨架 · 典雅稳重 | 典雅，横细竖粗对比明显 |
| `caiyun` | 华文彩云 | 空心装饰 · 轻盈跳脱 | 装饰性最强，但细节多，小尺寸会糊 |

## 四、关于篆体 / 花体

- **系统不含篆书字体**，Windows 自带的中文书法体只有隶书 / 行楷 / 新魏 / 彩云 / 舒体 / 姚体等（上表已覆盖）。
- 用生成式模型画篆书「简」**字形不可靠**——实测两张概念图（`ai-concepts/`）字形均不成立，且带水印、配色不受控，**未纳入候选**，仅留作风格参考。
- 需要真正的篆体 / 花体时，把自备字体文件（`.ttf` / `.otf` / `.ttc`）丢进 **`design/icon/fonts/`**，`render.py` 会自动把它加入候选（默认字重补偿 12），无需改代码。

## 五、资产清单

```
scan_fonts.py            扫描系统字体，列出真正含某汉字的字体
render.py                主渲染脚本（多字体方案 / 对比图 / 导出图标集）
gen.py                   概念图生成脚本（调用云端图片生成服务，仅作风格参考）
ai-concepts/             生成式概念图（字形不准确，仅参考）
fonts/                   自备字体放这里，自动成为候选方案（当前为空）
final/
  preview.png            九套方案对比图（评审用）
  hanzi/<key>-1024.png   各方案 1024 图标（品牌渐变方圆形底）
  hanzi/<key>-mark.png   各方案透明底字形（托盘 / 单色）
  logo-selected.png      经 --apply 选定的方案
  tauri-icons/           选定后导出的完整图标集（与 src-tauri/icons 同名同尺寸）
archive/easy/            上一版「Easy」字母字标方案（已废弃，留档）
```

## 六、重新生成 / 应用

```powershell
py -3 design/icon/render.py                 # 渲染全部方案 + 对比图
py -3 design/icon/render.py --apply hupo    # 选定方案 → 导出完整图标集
```

依赖 Pillow（本机 `py -3` 已装）。改底色 / 字面占比 / 字重补偿，只需调整
`render.py` 顶部的品牌令牌、`GLYPH_RATIO` 与 `STYLES` 表的第 5 列。

应用到客户端（覆盖前请关闭运行中的 `easy-interview.exe`）：

```powershell
Copy-Item design/icon/final/tauri-icons/* src-tauri/icons/ -Force
```

托盘图标取 `app.default_window_icon()`，覆盖后一并生效。
覆盖属于客户端变更：需同步 `ai-doc/技术方案.md` 第 15 章视觉规范，并单独提交。
